# مكتبة العلماء السلفية

تطبيق أندرويد لكتب العلماء، يعتمد على «تراث» مصدرًا للنصوص.

## الحالة
- الدفعة الأولى: الهيكل، والعلماء الثمانية، والتنقل بين الأقسام الثلاثة.
- الدفعات القادمة: كتب كل عالم من تراث، والبحث، والتنزيل بدون إنترنت، والمحفوظات بالألوان، والفوائد، والكتب الصوتية.

## البناء
يُبنى تلقائيًا عبر GitHub Actions (`.github/workflows/build.yml`)، ويُنتج ملف APK كمخرج للتنزيل.
